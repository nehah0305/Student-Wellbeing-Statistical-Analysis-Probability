# Student-Wellbeing-Statistical-Analysis-Probability
This project focuses on conducting a comprehensive statistical analysis of a Student Wellbeing Survey dataset using Python in a Jupyter/Google Colab notebook. The analysis begins with inspecting the dataset and calculating descriptive statistics, including the mean, median, mode, range, variance, standard deviation, quartiles, and interquartile range for Weekly Study Hours, Average Sleep Hours, Daily Screen Time, Stress Score, and Academic Readiness Score. The project also identifies outliers using the IQR method for selected variables and compares statistical measures before and after removing outliers. Probability concepts are applied to examine relationships between part-time employment, stress levels, scholarships, and exercise habits, including union, intersection, conditional, and independence probabilities. Bayes’ theorem is further used to calculate and verify conditional probability. Finally, the Academic Readiness Score is analyzed using the normal distribution by calculating Z-scores for the highest- and lowest-scoring students and applying the 68-95-99.7 empirical rule. The project concludes with five meaningful statistical observations based on the findings, with each analysis presented using the relevant formula, Python calculation, numerical result, and brief interpretation.
